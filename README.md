# Outfit Planner

Plan a week of outfits with reference photos for each day, then check today's look each morning.

Live page: https://claude.ai/artifact/L9zNxD2kwoP6szyi9yuWpK

- `index.html` — the whole app (single page, published as a claude.ai Artifact)
- Photos are stored in the artifact's asset storage; which photos belong to which day, plus notes, live in its database (`days/mon` … `days/sun`).
